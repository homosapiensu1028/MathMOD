# Math Proof Board (Minecraft 1.21.1 / NeoForge)

幾何学の証明を黒板上で組み立て、完成時に検証し、証明した命題を定理ライブラリへ登録して再利用するMODの初期実装です。

> **実装状況を正確に記載しています。** この作業環境では外部ネットワークに接続できず、NeoForge Gradle依存関係を取得できなかったため、Minecraftを起動しての統合ビルド確認は未実施です。純Javaの証明コアは `javac` でコンパイルし、定理適用・変数置換・推移律・検証拒否のスモークテストを実行しています。

## 対象環境

- Minecraft Java Edition 1.21.1
- NeoForge 21.1.262
- Java / JDK 21
- Windows 10/11 推奨

## Prism Launcherへ導入する最短手順

1. JDK 21をインストールします。
2. ZIPを展開し、`build.bat` をダブルクリックします。初回ビルドにはインターネット接続が必要です。
3. 成功すると `dist\mathproof-1.0.0.jar` が作成されます。
4. Prism Launcherの対象インスタンスを右クリック →「編集」→「Mods」を開き、このJARを一覧へドラッグします。
5. Minecraft 1.21.1 / NeoForge 21.1.262 で起動し、Mキーを押します。

## ビルド（Windows PowerShell）

1. JDK 21をインストールします。
2. ZIPを展開します。
3. 展開先の `MathProof-1.21.1` フォルダでPowerShellを開きます。
4. 次を実行します。

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build.ps1
```

スクリプトはGradle 8.12を `%LOCALAPPDATA%\MathProofBuild` にダウンロードして `clean test build` を実行します。成功すると `dist\mathproof-1.0.0.jar` へコピーされます。`-PrismInstancePath` を指定すると、対象インスタンスの `mods` フォルダへ直接コピーすることもできます。NeoForge 1.21.1が必要です。

## 起動・操作

- ゲーム内で **Mキー** を押すと数学証明黒板を開きます。
- 左の資源パレットから式テンプレートや記号をドラッグし、入力欄または黒板に置きます。
- 黒板に置いた資源チップをクリックすると、前提入力欄へ追加できます。
- 前提入力欄に式を入力し、「＋ 前提を追加」を押します。
- 証明目標を入力し、「目標を設定」を押します。
- 「定理: …」ボタンで定理を切り替え、「定理を適用」を押します。
- 「推移律」は等式・角度等式・点の等式の共有項から、新しい等式を導きます。
- 「検証」で目標とすべての導出ステップを再検証します。
- 検証成功後に「定理として登録」を押すと、ユーザー定理ライブラリへ追加します。
- ノードはドラッグで移動できます。配置・証明・定理は `config/mathproof/` に保存されます。

## 現在対応する式

```text
AB = AC
∠ABC = ∠BCA
△ABC
△ABC ≅ △DEF
AB ∥ CD
collinear(A,B,C)
A = B
¬(AB = AC)
```

`BA = CA` と `AB = AC` のような線分端点の順序差や、角度の両端の順序差は正規化します。定理の変数対応により、二等辺三角形の底角定理を `ABC` から `PQR` などへ適用できます。

## 初期定理ライブラリ

- 二等辺三角形の底角定理と逆
- 三辺相等による合同
- 二辺夾角による合同
- 一辺とその両端の角による合同
- 合同な三角形の対応する辺・角
- 含意の適用（基本的な述語表現）

定理適用時は前提に一致する命題を黒板上から探し、変数の対応と利用した事実IDを保存します。完成時の検証では保存済みの説明文を信じるだけでなく、依存先の事実を再帰的に検証し、該当する定理をもう一度適用して結論を再計算します。

## 厳密性と現在の制限

- **通常証明**：対応している命題と定理適用、および推移律を検証します。
- **背理法・帰納法**：UIから選択できますが、局所仮定の導入・解除や帰納法証明オブジェクトの完全検証はまだ実装していません。したがって、現時点では検証を成功扱いせず、定理登録も拒否します。
- 任意のユーザー入力が自動的に真になるわけではありません。入力を「前提」として追加した場合、その証明問題内で仮定として扱います。
- 初期版は形式化された幾何命題の一部のみを対象にします。任意の高校幾何・作図・円周角・相似など、未登録の規則を自動で証明するものではありません。
- 定理の一般化は、登録した証明で使った前提をそのまま定理の前提として保存する保守的な方式です。不要な前提を自動で除去する最小前提解析は未実装です。
- 保存ファイルはシングルプレイ用のローカルデータです。設定ファイルを直接編集したデータの真正性を保証する署名機構はありません。

## 開発者向け

数学コアはMinecraftクラスに依存しない `dev.mathproof.core` に置いてあります。

- `Statement` / `StatementParser`: 命題モデルと式解析
- `TheoremDefinition` / `TheoremLibrary`: 定理定義と分類ライブラリ
- `ProofSession` / `ProofFact`: 証明セッションと依存関係
- `ProofEngine`: 定理マッチング、推移律、完成時検証
- `ProofBoardScreen`: Minecraft側の黒板UI、ドラッグ操作、保存

テストは `src/test/java/dev/mathproof/core/ProofEngineTest.java` にあります。
